H1 Kart okutma (Faz 3): mat siyah, pah kırık NFC okuyucu (üstte "NFC" yazısı + daire içinde dalga simgesi, kablo, kenarda yavaş akan RGB led şeridi), ahşap dokulu masa, mavi metalik kart yumuşak köşeli, kartı tutan el/parmak (stilize ama ölçülü), kart yaklaşınca alan halkaları ve led tepkisi, onayda yeşil yanma+ses. Yakın çekim ve yan kesit görünümü.
H2 POS + kart şeması (Faz 3/5): POS gövdesi (ekran, tuş takımı, temassız bölge) ve yanında yarı saydam kart; "Energy + Data via NFC" okunur etiketleri; anten bobini (turuncu-bakır), güvenli çip; mavi eğri sinyal yayları POS'tan karta. Teknik görünümde teknik çizim, gerçek görünümde fiziksel malzeme.
H3 Kart anatomisi patlatılmış (Faz 2/3): 3 katman ayrışır: üst katman (altın temas pedli çip modülü + altında küçük silikon die), orta katman (delik + bağlantı telleri), alt katman (çok sarımlı altın/bakır anten bobini + kapasitör). Katmanlar animasyonla ayrılıp birleşir, her parça tıklanınca ad+işlev; kapak/yarı saydam geçişi.
H4 Mimari görünüm (Faz 3, 9): koyu zemin, izometrik neon katmanlı yapı: Application / Business Logic / Data Layer katmanları ortada; çevrede API Gateway, Auth, Notification, Microservices, Message Queue, SQL DB, NoSQL DB, Cloud Storage kutuları; aralarında akan ışıklı çizgiler (istek yönü oklu). Her kutu tıklanabilir (işlev, hata durumu). İşlem akışı bu görünüm üzerinde adım adım izlenir (kart okutma → validatör → gateway → auth → fare service → queue → DB → yanıt).
H5 Durak sahnesi (Faz 4): alacakaranlık gökyüzü gradyanı, uzakta gökdelenler, üst geçit/viyadük, bitki ve ağaçlar, ışıklı durak kabini + ekran (hat 32 varış bilgisi), dokunsal kaldırım şeridi, modern elektrikli otobüs (ön led, hat numarası ekranı, geniş kapı, rampa), kalabalık: ebeveyn+çocuk, yaşlı, sırt çantalı yolcu, TEKERLEKLİ SANDALYE kullanan yolcu (erişilebilirlik), telefonu olan ana karakter; kişiler farklı boy/kıyafet/animasyon (yürüme, bekleme, binme). Instancing ile performans.
Kalite kapısı: her sahnede ≥3 ışık, gölge, malzeme çeşitliliği, ≥20 etiketli/ayrıntılı nesne (Faz 3 sahnesi ≥10), arka plan boş değil (çevre ayrıntısı). Düşük cihaz için kalite anahtarı (gölge/bloom kapat).
